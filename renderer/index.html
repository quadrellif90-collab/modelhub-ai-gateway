    Strategie: order = lista manuale · cheapest = prezzo · fastest = TTFT medio · least-used = carico giornaliero · random · cascade = cheap→strong con validazione.

    Trascina per riordinare. Le app collegate usano il profilo come model.

      Prezzi ($/Mtok)

      Default per provider; override per modello in pricing.json. I modelli free costano sempre 0.

      Import massivo chiavi provider

      Incolla un JSON { "provider": "key", ... }. Sostituisce/aggiunge chiavi esistenti.

      Chiavi gateway

      Le app collegate devono inviare Authorization: Bearer <key> (o x-api-key). Se vuoto = nessuna protezione. Le chiavi sono mostrate una sola volta al momento della creazione.

      Cache semantica

      Layer opzionale sopra la cache esatta: embed del prompt → similarità coseno. Richiede un modello embedder nel registry. Disattivata di default.
